# 目標篩選與排序

清單頁的「完成狀態」與「目標分類」可以組合使用，分類包含「未分類」。「清除篩選與排序」可回到全部狀態、全部分類、預設順序。選項只影響目前頁面的顯示，不修改資料，也不會在重新載入後保留。

- **預設順序**：使用儲存的 `order` 由小到大。
- **期限由近到遠**：最早期限先顯示，沒有期限的項目放最後。
- **優先級由高到低**：高、中、低、無優先級。
- **最近更新**：`updatedAt` 由新到舊，沒有有效更新時間的項目放最後。

排序值相同時，以 `order`、項目 ID 作為固定次序，不依瀏覽器語系變動。若分類被其他成員刪除，分類選項會回到「全部分類」並提示；完成狀態與排序仍保留。

「顯示 N / 共 M 個項目」區分目前結果與清單總數，頂端完成進度仍計算整份清單。新增、完成、刪除及每 15 秒同步都會重新套用目前條件；例如在「未完成」下勾選完成，該項目便會從結果消失。若沒有符合條件的項目，可清除篩選。

篩選不會關閉編輯器或清除尚未儲存的內容。編輯中的項目離開結果時會提示，仍可儲存或取消；遠端版本衝突與刪除仍沿用草稿保留及比較機制。JSON／CSV 匯出永遠包含已儲存的完整清單，不受篩選影響。
